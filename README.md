# Science Calendar — support site

The support and privacy pages for the **Science Calendar** iOS app, served by
GitHub Pages because the App Store requires both to be reachable at a public URL.

- `index.html` — support page and FAQ (Apple's *Support URL*)
- `privacy.html` — privacy policy (Apple's *Privacy Policy URL*)
- `style.css` — shared styling, using the app's own palette

This repo holds the website only. The app source is elsewhere and is private.
